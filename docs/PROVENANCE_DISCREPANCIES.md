## Discrepancy 1: Temporal Macro-F1 Delta Sign Convention ($\Delta_j$)

* **Manuscript Statement:** Early drafts of Section 4.2 and Table 9 informally described degradation as $\Delta = \text{Reference} - \text{Target}$ in prose, while equations in Section 3 formulated delta as Target minus Reference.
* **Code Statement:** The evaluation scripts (`src/metrics.py`, `scripts/run_table9.py`, `climate_temporal_f1.py`, `yelp_temporal_f1.py`) strictly implement:
  $$\Delta_j = \text{MacroF1}(T_j) - \text{MacroF1}(T_0)$$
  where negative deltas represent performance degradation and positive deltas represent improvement.
* **Run Metadata Statement:** Summary CSVs (`outputs/tables/RQ2_Table9_summary.csv`) report signed values (e.g. Climate DistilBERT $T_2$ delta: $-0.0911$; Qwen $T_2$ delta: $-0.0655$).
* **Saved-Output Evidence:** All LaTeX tables and CSV summaries generated by `reproduce.py --table9` use this standard sign convention.
* **Recommended Manuscript Correction:** Ensure Equation (5) and the caption of Table 9 explicitly state:
  $$\Delta_j = \text{MacroF1}(T_j) - \text{MacroF1}(T_0)$$
  *"Negative values indicate performance decline under temporal shift; positive values indicate generalization gain."*

## Discrepancy 2: Output Token Generation Limit (`num_predict`)

* **Manuscript Statement:** Appendix B states models were instructed to generate a single structured JSON object containing three keys (`label`, `confidence`, `abstain`).
* **Code Statement:**
  * The unified master runner (`run_paper_models.py`) sets `NUM_PREDICT = 96`.
  * Earlier historical exploratory code (`sample_and_run_mvbe`) set `NUM_PREDICT = 80`.
* **Run Metadata Statement:** Complete JSON responses for binary classification across all evaluated models span between 28 and 44 tokens.
* **Saved-Output Evidence:** Across all 40,000+ saved prediction records in `archives/`, the `raw_response` column shows zero truncated outputs or syntax cut-offs.
* **Recommended Manuscript Correction:** Report that generation was capped at `num_predict` $\le 96$ tokens, which safely accommodates the 3-key JSON output payload without risk of mid-generation truncation.

## Discrepancy 3: Historical Yelp DistilBERT Checkpoints (Seeds 45 and 46)

* **Manuscript Statement:** Section 3 states that task-adapted DistilBERT was fine-tuned across five seeds (42–46) on historical training data, selecting the best epoch checkpoint using validation Macro-F1.
* **Code Statement:** `sentiment_frozen_and_adapted_v4_7000_3000_MEMORY_SAFE.py` configures `load_best_model_at_end=True`, `metric_for_best_model="macro_f1"`, and `EarlyStoppingCallback(early_stopping_patience=1)`.
* **Run Metadata Statement:** In partial run `sentiment_adapted_on_frozen_20260722`, execution aborted mid-save during seed 45 (`checkpoint-875` saved, `checkpoint-1750` partial). In completed run `sentiment_joint_20260726_122931`, post-training diagnostics (`adapted_training_diagnostics_seed45.json` and `seed46.json`) confirm 7,000 train rows, 3,000 validation rows, and completed validation scores (`val_macro_f1=0.9140` and `0.9220`), but intermediate per-epoch checkpoints were pruned (`save_total_limit=1`).
* **Saved-Output Evidence:** Documented in detail in `C:\Research\PaperRevision\Yelp_checkpoint_gate.md`. The final 5-seed predictions produce ranking stability and exact parity with Table 8.
* **Recommended Manuscript Correction:** State in Section 3 that models were trained with `save_total_limit=1` and `load_best_model_at_end=True`, with post-training diagnostics verifying validation Macro-F1 convergence across all five seeds.
